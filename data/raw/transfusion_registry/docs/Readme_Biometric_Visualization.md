# Biometric Data Visualization

**Author:** Elina Nuerenberg-Goloub — **Last revised:** 2026-08-18

This module generates publication-quality visualizations for biometric descriptive statistics from transfusion registry data.

## Purpose

Creates visual representations of patient demographic and biometric data for use in scientific reports, presentations, and publications.

## Input Requirements

The script requires the output from the biometric analysis:
- `biometric_descriptives_detailed.json` (generated by `run_analysis.py`)

## Usage

### Basic Usage

```bash
python3 run_visualize_biometrics.py <analysis_output_directory>
```

### Example

```bash
python3 run_visualize_biometrics.py test_data_150patients
```

This command will:
1. Read from `test_data_150patients/biometric_descriptives_detailed.json`
2. Create directory `test_data_150patients/figures/` (if it doesn't exist)
3. Generate all visualizations in that directory

## Output Files

The script generates 5 files in the `figures/` subdirectory:

### 1. biometric_gender_distribution.png
- Pie chart showing gender distribution
- Title includes total N
- Legend shows categories with percentages
- Colors: Male (dark blue #0f3971), Female (red #ef312d), Not provided (gray #b3b3b3)

### 2. biometric_violins.png
- Violin plots with embedded box plots for continuous variables (Age, BMI)
- Shows distribution shape (violin), median line, quartiles (box), mean (red diamond), and outliers
- Title includes N for each variable
- Grey color (#808080) as demographics are not product-specific

### 3. biometric_age_by_gender.png
- Violin plot comparing age distribution between Male and Female
- Orange (#f46d43) for Male, Light blue (#74add1) for Female
- X-axis labels show gender with sample size: "Male\n(n=...)", "Female\n(n=...)"
- Red diamond marker indicates mean value
- Outlier points shown, colored to match their group
- Useful for identifying age differences between sexes in the cohort

### 4. biometric_bmi_by_gender.png
- Violin plot comparing BMI distribution between Male and Female
- Same color scheme as age by gender
- X-axis labels show gender with sample size: "Male\n(n=...)", "Female\n(n=...)"
- Red diamond marker indicates mean value
- Outlier points shown, colored to match their group

### 5. biometric_summary_table.csv
- Statistical summary table in CSV format
- Includes: Gender, Age (overall and by sex), BMI (overall and by sex), Blood Group
- Columns: Variable, N, Mean±SD, Median [IQR], Range
- Can be opened in Excel or imported into other tools

## Design Specifications

All visualizations follow these specifications:
- **Resolution**: 300 DPI (publication quality)
- **Format**: PNG for figures, CSV for tables
- **Font sizes**: Title 24pt, Axis labels 20pt, Tick labels 18pt, Legend 18pt
- **Background**: White

### Color Schemes

**Gender Distribution Pie Chart:**
- Male: #0f3971 (dark blue)
- Female: #ef312d (red)
- Not provided: #b3b3b3 (gray)

**Gender-Stratified Violin Plots:**
- Male: #f46d43 (Orange)
- Female: #74add1 (Light blue)
- Mean marker: #d73027 (Red diamond)

## Dependencies

Required Python packages:
- matplotlib
- json (standard library)
- csv (standard library)

## Notes

- Violin plots show the full distribution shape plus embedded box plot statistics
- **Median** shown as horizontal line inside box (same color as group)
- **Mean** shown as red diamond marker (#d73027)
- **Outliers** shown as individual points beyond whiskers (colored to match group)
- Clean publication style without annotation text
- All figures use white background, suitable for direct inclusion in scientific publications
- Matplotlib runs on the headless 'Agg' backend, so figures render without a display
- Raw data path required for violin plot generation: it is auto-detected as `<analysis_dir_name>.csv` in the parent or grandparent directory of the analysis directory, or can be passed explicitly as a third argument to `visualize_biometrics.py`
- Plots are rendered only from real input data: if raw data is unavailable for a variable, that plot is skipped with a warning (no simulated distributions are ever drawn)
