# Dosage Statistics Visualization

**Author:** Elina Nuerenberg-Goloub — **Last revised:** 2026-08-18

This module generates publication-quality visualizations for dosage statistics from transfusion registry data.

## Purpose

Creates visual representations of dosage distributions for each blood product, showing the typical ranges and variability. **Histograms (horizontal bar charts) are used instead of violin/box plots** because blood products come in standard doses, making the data discrete rather than continuous.

## Input Requirements

The script requires:
- `treatment_statistics_detailed.json` (generated by `run_treatment_analysis.py`)
- Raw CSV data file (for histogram generation)

## Usage

### Basic Usage

```bash
python3 run_visualize_dosages.py <analysis_output_directory>
```

### Example

```bash
python3 run_visualize_dosages.py test_data_150patients
```

This command will:
1. Read from `test_data_150patients/treatment_statistics_detailed.json`
2. Load raw data from `../synthetic test data/test_data_150patients.csv` (auto-detected as `<analysis_dir_name>.csv` in the parent directory; an explicit path can be passed as a third argument)
3. Create directory `test_data_150patients/figures/` (if it doesn't exist)
4. Generate all visualizations in that directory

If the raw data file cannot be found, the histograms are skipped with a warning - plots are only ever rendered from real input data.

## Output Files

The script generates 8 files in the `figures/` subdirectory:

### Histograms (7 PNG files)

Individual horizontal bar charts for each product-unit combination showing dosage distributions

### CSV Table

#### dosage_summary.csv
- Comprehensive table of all products and their dosage statistics
- Columns: Product, Unit, N, Mean, SD, Median, Q25, Q75, Min, Max, Histogram
- "Histogram" column indicates Yes/No for whether a plot was generated
- Machine-readable format for further analysis

## Design Specifications

### Histogram Features

**Bar Chart Components:**
- **Horizontal bars**: Each unique dose value gets its own bar
- **Consistent bar width**: All bars same height for clean appearance
- **White edges**: Clearly separates adjacent bars
- **Product-specific colors**: Matches color scheme used across all visualizations

**Statistics Annotation:**
- **Median and IQR**: Displayed in bottom-right corner
- **Format**: "Median: X, IQR: Y-Z"
- **White background box**: For readability

**Layout:**
- **Horizontal orientation**: Dose values on y-axis, frequency on x-axis
- **Y-axis labels**: Show actual dose values (e.g., 250, 300, 500, 600 ml)
- **X-axis**: Frequency count

**Title:**
- Format: "Product name (n = number of administrations)"
- Clean product names (abbreviations removed)

| Fibrinogen | Dark blue | #4575b4 |
| Albumin | Light blue | #abd9e9 |
| Antithrombin III | Light orange | #fdae61 |

### General Specifications

- **Resolution**: 300 DPI (publication quality)
- **Format**: PNG for figures, CSV for table
- **Font**: Arial, black text
- **Background**: White
- **Minimum observations**: 15 required for histogram generation
- **Backend**: Matplotlib runs on the headless 'Agg' backend, so figures render without a display
