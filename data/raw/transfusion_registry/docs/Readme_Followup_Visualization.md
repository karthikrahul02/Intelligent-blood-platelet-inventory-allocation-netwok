# Follow-Up Statistics Visualization

**Author:** Elina Nuerenberg-Goloub — **Last revised:** 2026-08-18

This module generates publication-quality visualizations for follow-up statistics from transfusion registry data at two timepoints (3-month and 1-year).

## Purpose

Creates visual representations of patient outcomes following transfusion, tracking changes in physical capacity, frailty, and clinical outcomes. Essential for assessing long-term patient recovery and identifying any adverse events.

## Input Requirements

The script requires the output from the follow-up analysis:
- `followup_statistics_detailed.json` (generated by `run_followup_analysis.py`)

## Usage

### Basic Usage

```bash
python3 run_visualize_followup.py <analysis_output_directory>
```

### Example

```bash
python3 run_visualize_followup.py test_data_150patients
```

This command will:
1. Read from `test_data_150patients/followup_statistics_detailed.json`
2. Create directory `test_data_150patients/figures/` (if it doesn't exist)
3. Generate all visualizations in that directory

## Output Files

The script generates 8 files in the `figures/` subdirectory:

### Bar Chart (1 PNG file)

#### 1. followup_baseline_comparison.png
- Grouped bar charts comparing baseline vs 3-month follow-up **category
  distributions** (number of patients per category, derived from the
  transition-matrix marginals) — both measures are ordinal, and the
  physical-capacity codes index the categories 1, 3, 4, 10, and >10 MET,
  so no means of category codes are plotted
- Two measures shown side-by-side:
  - **Physical Capacity** (categories 1 MET to >10 MET): Higher is better
  - **Clinical Frailty Scale** (grades 1-9): Lower is better
- Refusal answers (code 0) are excluded from the underlying paired data and change counts
- Color coding:
  - Red bars: Baseline category counts
  - Blue bars: 3-month follow-up category counts
- Text box showing change summary: improved/unchanged/worsened counts
- Shows improvement/worsening in patient functional status

## Design Specifications

### Bar Chart Features

**Layout:**
- **Side-by-side subplots**: Physical Capacity and Clinical Frailty Scale
- **Paired bars**: Baseline (red) and 3-Month Follow-up (blue)
- **Bar width**: 0.5
- **Grid**: Horizontal gridlines for easier value reading

**Color Coding:**
- **Baseline**: Red (#ef312d) with 70% transparency
- **3-Month Follow-up**: Blue (#0f3971) with 70% transparency
- **Borders**: Black (1.5px width)

**Error Bars:**
- Black whiskers showing +1 standard deviation (upward only)
- Symmetric representation of variability
- Cap at top (5px width)
- Line width: 1.5px
- No value labels on chart for cleaner presentation

**Change Summary:**
- Text box in upper right showing:
  - Improved: [count]
  - Unchanged: [count]
  - Worsened: [count]
- White background with gray border

**Title:**
- Format: "Measure name (n = paired observations)"
- Example: "Physical Capacity (n = 14 paired)"

**Y-axis:**
- "Number of patients" (category counts; integer ticks)
- Data-driven limits with headroom above the tallest bar

### Donut Chart Features

All donut charts follow these specifications:

**Layout:**
- **Donut style**: White center with ring width of 0.6
- **Start position**: Largest slice at south (bottom, 270°)
- **Direction**: Clockwise, descending by size
- **Separators**: Thin white lines (0.5px) between slices

**Color Coding:**
- Colors assigned by slice size (largest to smallest):
  - 1st largest: Dark blue (#0f3971)
  - 2nd largest: Dark red (#b12320)
  - 3rd largest: Light blue (#159ad6)
  - 4th largest: Red (#ef312d)
  - 5th largest: Orange (#f7973e)
  - 6th largest: Teal/green (#5a9f95)
  - 7th largest: Brown (#a15444)
- **"Unknown", "no answer", and "Cannot answer" categories are always gray (#b3b3b3)** regardless of size

**Legend:**
- Positioned close to donut (right side)
- Sorted by size (largest to smallest)
- Gray categories always at end of legend
- Format: "Category description (...%)"

**Title:**
- Format: "Outcome name - Timepoint (n = total respondents)"
- Example: "Anaemia Diagnosed - 3-Month (n = 29)"

### General Specifications

- **Resolution**: 300 DPI (publication quality)
- **Format**: PNG for figures, CSV for table
- **Font**: Arial, black text
- **Background**: White
- **File naming**: Clean, lowercase with underscores
