# Indication/Intervention Statistics Visualization

**Author:** Elina Nuerenberg-Goloub — **Last revised:** 2026-08-18

This module generates publication-quality visualizations for indication and intervention descriptive statistics from transfusion registry data.

## Purpose

Creates visual representations of clinical indications for each blood product, showing the distribution of reasons for administration. Essential for understanding clinical decision-making and appropriate use of blood products.

## Input Requirements

The script requires the output from the indication/intervention analysis:
- `indication_intervention_statistics_detailed.json` (generated by `run_indication_analysis.py`)

## Usage

### Basic Usage

```bash
python3 run_visualize_indications.py <analysis_output_directory>
```

### Example

```bash
python3 run_visualize_indications.py test_data_150patients
```

This command will:
1. Read from `test_data_150patients/indication_intervention_statistics_detailed.json`
2. Create directory `test_data_150patients/figures/` (if it doesn't exist)
3. Generate all visualizations in that directory

## Output Files

The script generates 9 files in the `figures/` subdirectory:

### Donut Charts (8 PNG files)

Individual donut charts for each blood product showing indication distribution:

#### 1. indication_red_blood_cell_concentrate.png
- Indications for red blood cell concentrate (erythrocytes)
- Main categories: Hemoglobin levels, Massive transfusion
- Most common: Hb 7-8 g/dl with anemic hypoxia signs

#### 2. indication_fresh_frozen_plasma.png
- Indications for fresh frozen plasma
- Main categories: Massive transfusion, Dilutional coagulopathy
- Most common: Massive transfusion

#### 3. indication_platelet_concentrate.png
- Indications for platelet concentrate
- Main categories: Various platelet thresholds, Platelet disorders
- Most common: Plt <50,000/µl with bleeding/intervention

#### 4. indication_ppsb.png
- Indications for PPSB (prothrombin complex concentrate)
- Main categories: Coagulation reversal, INR correction
- Most common: Massive transfusion, Anticoagulant reversal

#### 5. indication_fibrinogen.png
- Indications for fibrinogen
- Main categories: Coagulopathy types, Hypofibrinogenemia
- Most common: Massive transfusion

#### 6. indication_albumin.png
- Indications for albumin
- Main categories: Hypoalbuminemia, Volume replacement
- Most common: Hypoalbuminemia with edema/ascites

#### 7. indication_iron_i.v.png
- Indications for intravenous iron
- Main categories: Failure of oral iron treatment, blood loss, malabsorption, functional iron deficiency

#### 8. indication_antithrombin_iii.png
- Indications for antithrombin III
- Main categories: AT deficiency, Heparin resistance
- Most common: AT <70% with heparin resistance

### CSV Table (1)

#### 9. indication_summary.csv
- Comprehensive table of all products and their indications
- Columns: Product, Indication, Count, Percentage
- Sorted by size within each product
- "Other" category always at the end

## Design Specifications

### Donut Chart Features

All donut charts follow these specifications:

**Layout:**
- **Donut style**: White center with ring width of 0.6
- **Start position**: Largest slice at south (bottom, 270°)
- **Direction**: Clockwise, descending by size
- **Separators**: Thin white lines (0.5px) between slices

**Color Coding:**
- Colors assigned by slice size (largest to smallest):
  - 1st largest: Dark blue (#0f3971)
  - 2nd largest: Dark red (#b12320)
  - 3rd largest: Light blue (#159ad6)
  - 4th largest: Red (#ef312d)
  - 5th largest: Orange (#f7973e)
  - 6th largest: Teal/green (#5a9f95)
  - 7th largest: Brown (#a15444)
- **"Other" is always gray (#b3b3b3)** regardless of size
- **Residual wedge**: if some documented indications fall outside the classified categories, an explicit light-gray (#d9d9d9) "Not classified" wedge is added so the donut geometry matches the printed percentages (small categories are not visually inflated)

**Legend:**
- Positioned close to donut (right side)
- Sorted by size (largest to smallest)
- "Other" always at the end of legend
- Format: "Indication description (...%)"

**Title:**
- Format: "Product name (n = documented indications)"
- Clean product names (abbreviations removed)
- Note: n reflects only administrations with documented indications, not total administrations

### General Specifications

- **Resolution**: 300 DPI (publication quality)
- **Format**: PNG for figures, CSV for table
- **Font**: Arial, black text
- **Background**: White
- **File naming**: Clean, lowercase with underscores
- **Backend**: Matplotlib runs on the headless 'Agg' backend, so figures render without a display

## Dependencies

Required Python packages:
- matplotlib
- json (standard library)
- csv (standard library)
