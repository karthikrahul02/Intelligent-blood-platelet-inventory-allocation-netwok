# Temporal Volume Visualizations

**Author:** Elina Nuerenberg-Goloub — **Last revised:** 2026-08-18

This module generates publication-quality visualizations for blood product volume trends over time.

## Purpose

Creates visual representations of blood product usage patterns to:
- Track volume trends over time
- Identify seasonal variations
- Support resource planning and forecasting
- Monitor changes in clinical practice

## Input Requirements

The script requires the output from the temporal volume analysis:
- `temporal_volumes_detailed.json` (generated by `run_temporal_volume_analysis.py`)

## Usage

### Basic Usage

```bash
python3 run_visualize_temporal_volumes.py <analysis_output_directory>
```

### Example

```bash
python3 run_visualize_temporal_volumes.py test_data_150patients
```

This command will:
1. Read from `test_data_150patients/temporal_volumes_detailed.json`
2. Create directory `test_data_150patients/figures/` (if it doesn't exist)
3. Generate all visualizations in that directory

## Output Files

The script generates **20+ PNG files** in the `figures/` subdirectory: one monthly and one quarterly volume chart per product-unit combination present in the data, plus two administration-count charts (stacked and total). All product classes with data get charts, including Iron i.v. and Machine Autotransfusion.

## Design Specifications

### Monthly Bar Charts

**Chart Type**: Vertical bar chart

**Design Elements**:
- **Bars**: Red (#ef312d), 80% opacity
- **Borders**: Black, 1.5px width
- **Width**: 0.6 (leaving space between bars)
- **Grid**: Horizontal gridlines, dashed, 30% opacity
- **Y-axis**: Starts at 0, formatted with commas for thousands
- **X-axis**: Month names with year, rotated 45°

**Month Label Format**:
- **4-letter months**: Full name (e.g., "July 2025", "June 2024", "May 2025", "April 2024")
- **Other months**: 3-letter abbreviation (e.g., "Jan 2025", "Feb 2024", "Mar 2025", "Aug 2024", "Sep 2024", "Oct 2024", "Nov 2024", "Dec 2024")

**Layout**:
- **Size**: 10" × 6" (wide format for time series)
- **Title**: "Product name - Monthly Volume (N months)"
- **Y-axis label**: "Total Volume (unit)"
- **X-axis label**: "Month"

**Features**:
- Auto-scaling with 10% padding above maximum
- Clear month names for easy reading
- Discrete bars (not connected) reflect independent monthly totals
- Professional appearance for reports/publications

### Quarterly Bar Charts

**Chart Type**: Vertical bar chart

**Design Elements**:
- **Bars**: Dark blue (#0f3971), 80% opacity
- **Borders**: Black, 1.5px width
- **Width**: 0.6 (leaving space between bars)
- **Grid**: Horizontal gridlines, dashed, 30% opacity
- **Y-axis**: Starts at 0, formatted with commas

**Layout**:
- **Size**: 10" × 6" (wide format)
- **Title**: "Product name - Quarterly Volume (N quarters)"
- **Y-axis label**: "Total Volume (unit)"
- **X-axis label**: "Quarter"
- **X-tick labels**: Rotated 45° (e.g., 2024-Q3, 2024-Q4)

**Features**:
- Clear quarter labels (YYYY-QX format)
- Consistent color scheme with monthly charts
- Easy comparison between quarters

### General Specifications

- **Resolution**: 300 DPI (publication quality)
- **Format**: PNG with white background
- **Font**: Arial, black text
- **Color scheme**: Matches other visualizations in the suite
- **File naming**: Descriptive, lowercase with underscores
- **Backend**: Matplotlib runs on the headless 'Agg' backend, so figures render without a display
- **Missing data**: Charts are rendered only from the analysis JSON; if a product-unit combination has no data, its chart is skipped with a console message (no simulated data is ever drawn)

## Data Quality

### Filters Applied

Same data quality filters as treatment analysis (applied during temporal volume analysis):

- **PPSB ml**: Excluded (clinically implausible)
- **Fibrinogen IU**: Excluded (non-standard unit)
- **Fibrinogen mg <500**: Excluded (implausibly low)

**Total**: 6 out of 1019 dosage records excluded (0.6%)

See `Readme_Data_Quality_Dosage.md` for details.

### Date Range

Visualizations include all available data from the dataset:
- Date range is automatically detected
- Incomplete months/quarters are included (e.g., partial current month)
- X-axis adjusts to actual date range

## Dependencies

Required Python packages:
- matplotlib
- json (standard library)
- datetime (standard library)
- pandas (for date handling)

## File Naming Convention

**Monthly bar charts** (red): `monthly_<product>_<unit>.png`
- Example: `monthly_ppsb_iu.png`

**Quarterly bar charts** (blue): `quarterly_<product>_<unit>.png`
- Example: `quarterly_ppsb_iu.png`

**Product name formatting**:
- Lowercase
- Spaces replaced with underscores
- Abbreviations removed (clean name used)
