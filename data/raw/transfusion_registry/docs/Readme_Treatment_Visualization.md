# Treatment Statistics Visualization

**Author:** Elina Nuerenberg-Goloub — **Last revised:** 2026-08-18

This module generates publication-quality visualizations for treatment descriptive statistics from transfusion registry data.

## Purpose

Creates visual representations of blood product administration, temporal trends, laboratory values, and administration frequency for use in scientific reports, presentations, and publications.

## Input Requirements

The script requires:
- `treatment_statistics_detailed.json` (generated by `run_treatment_analysis.py`)
- Raw CSV data file (for lab value violin plots)

## Data Quality Integration

The visualization module integrates with `lab_value_quality.py` to handle unit inconsistencies in laboratory values. See `Readme_Lab_Value_Quality.md` for details.

**Automated handling:**
- Detects unit confusion (e.g., platelets entered in thousands instead of actual count)
- Excludes outlier values from visualizations
- Displays corrected unit labels
- Generates quality reports for manual review

## Usage

### Basic Usage

```bash
python3 run_visualize_treatments.py <analysis_output_directory>
```

### Example

```bash
python3 run_visualize_treatments.py test_data_150patients
```

This command will:
1. Read from `test_data_150patients/treatment_statistics_detailed.json`
2. Load raw data from `../synthetic test data/test_data_150patients.csv` (auto-detected as `<analysis_dir_name>.csv` in the parent directory; an explicit path can be passed as a third argument)
3. Create directory `test_data_150patients/figures/` (if it doesn't exist)
4. Generate all visualizations in that directory

If the raw data file cannot be found, the plots that require it (lab value violin plots) are skipped with a warning - plots are only ever rendered from real input data.

## Design Specifications

### Product-Specific Colors

Lab value violin plots use colors matching the related blood product:

| Lab Parameter | Related Product | Color |
|---------------|-----------------|-------|
| Hemoglobin | Red blood cell concentrate | #a50026 (very dark red) |
| Platelets | Platelet concentrate | #f46d43 (orange) |
| Quick's test | PPSB | #74add1 (medium blue) |
| Fibrinogen | Fibrinogen | #4575b4 (dark blue) |
| Serum albumin | Albumin | #abd9e9 (light blue) |
| Ferritin | Iron i.v. | #e0f3f8 (light blue) |
| Transferrin saturation | Iron i.v. | #e0f3f8 (light blue) |

### General Specifications

- **Resolution**: 300 DPI (publication quality)
- **Format**: PNG for figures, CSV for tables
- **Font sizes**: Title 24pt, Axis labels 20pt, Tick labels 18pt, Legend 18pt, Bar labels 10-11pt
- **Background**: White
- **Minimum observations**: 15 paired values required for violin plots

### Gender Color Scheme

| Gender | Color | Hex Code |
|--------|-------|----------|
| Male | Orange | #f46d43 |
| Female | Light blue | #74add1 |
| Mean marker | Red diamond | #d73027 |
